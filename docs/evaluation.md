## 先講一件必須記住的事

**「單次插話品質評分表」在文獻裡不存在。** 這不是沒找到：

- Inner Thoughts 的 turn-taking appropriateness 是**整場對話一題、1–7 Likert、事後由旁觀者評分**，
  從未對「這一次插話好不好」做過標註或量測
- Overhearing Survey 把「如何評估 overhearing agent 的有用性」列為 **Challenge 2**，
  也就是**公認未解的開放問題**——給的是問題宣告，不是答案
- 兩篇都沒有提出或引用任何介入時機／品質的 benchmark

> **因此：第 1 層五維表的每一級判準都是我們自己寫的，沒有文獻背書。**
> 不要日後把它誤當成論文出處。

**建議的驗收方式**：上線前讓兩人標 20 個介入事件、算 Cohen's kappa，低於 0.6 就回頭改判準。

## 四個設計決定的依據

| 決定 | 依據 |
|---|---|
| **不能只用 Likert** | Inner Thoughts §7：三種明顯不同的主持風格，10 題 Likert **幾乎跑不出顯著差異**，即使受試者明明認得出來（辨識率 50–69%）。**Likert 平均值當調參訊號會是平的** |
| **必須包含「沒介入的機會點」** | Overhearing Challenge 2 明列**漏接**為三大失敗模式之一。只評分已發生的介入，會系統性遺漏一半的錯誤 |
| **必須是相對比較** | 兩篇都證實沒有 benchmark。絕對分數 3.8 沒意義；同場景兩組參數的 3.8 vs 3.1 才有意義 |
| **★ 每組設定至少跑 5 次** | 見下——**我們自己撞到的教訓** |

### 單次測試會給出完全錯誤的結論（2026-08-28 實測教訓）

模型選型時，單次測試的結果是：

```
gpt-5.4-mini  8/8 全對   ← 看起來是最佳選擇
gpt-5.6-luna  7/8（一個誤報）
```

同樣設定重跑 5 次之後：

| | healthy 誤報率 | divergent 誤報率 |
|---|---|---|
| gpt-5.6-luna | **3/5（60%）** | 0/5 |
| gpt-5.4-mini | 1/5（20%） | **4/5（80%）** |

**那個「8/8 全對」是運氣。** 兩個模型的弱點完全不同，而單次測試一個都沒暴露出來。

> **規定**：任何模型選型、prompt 修改、參數調整的比較，**每組至少跑 5 次**。
> 只看一次的結論一律視為無效。
>
> 這也實測印證了 Inner Thoughts §8.4 的自陳——他們的門檻是「反覆試誤」調的、
> 「導致互動不一致」。**LLM 的介入判斷本質上就是不穩定的**，
> 評估方法必須把這個特性納入，不能假裝它是確定性系統。

## 第 1 層：單次介入五維評分（1–5）（核心產出）

只對 TP 與 FP 事件打分。每一級都寫成**可觀察行為**，不用形容詞。

### 維度 1：必要性 —— 不介入的話會怎樣

| 分 | 判準 |
|---|---|
| 5 | 不介入會造成**可指認的損害**：議程走完仍無決議／錯誤事實被當前提繼續推論／有人被壓過去完全發不了言 |
| 4 | 不介入會**明顯拖慢**，但不致失控 |
| 3 | 有幫助但可有可無，**人類主席可能做也可能不做** |
| 2 | 群體**已在自我修正**（有人正要接話、講者正在收尾），介入是多餘的 |
| 1 | **完全沒有需要處理的問題**，介入純屬噪音 |

> **內建一致性檢查**：FP 事件依定義應落在 1–2。
> 若 FP 被打到 3 以上，代表第 0 層 ground truth 有問題，**回頭改標註手冊**。

### 維度 2：時機 —— 相對於理想介入點的偏移

| 分 | 判準 |
|---|---|
| 5 | **落在理想窗口內**。超時類：超時後 5 秒內；離題類：離題後第 2 段話內；停頓類：切在真實停頓（≥1.5 秒無人說話） |
| 4 | 早或晚 **1 個發言輪次**，仍然有效 |
| 3 | 早或晚 **2–3 輪**，效果打折但接得上 |
| 2 | **錯過窗口**：話題已轉走，或問題已自行解決 |
| 1 | **切在最壞的點**：切斷正在成形的關鍵論述／切在別人剛開口 3 秒內／**在發散期打斷腦力激盪** |

> 1 分的三個條件直接對應 PTFA 的兩個失敗模式，以及 `interruption-design.md` 的呻吟區 ×0.2 設計。

### 維度 3：正確性

| 分 | 判準 |
|---|---|
| 5 | 事實、指名、時間數據**全對** |
| 4 | 全對但**有一項不精確**（說「三分鐘」實際 2:20），不影響公信力 |
| 3 | **主張方向對但佐證有誤**（說「你們在重複」，實際只有部分重疊） |
| 2 | **指名錯人**或歸因錯人 |
| 1 | **事實錯誤，且該錯誤被與會者當真**並繼續往下推 |

### 維度 4：方式

| 分 | 判準 |
|---|---|
| 5 | 硬打斷／軟插入**選擇正確**、**≤2 句講完**、且**給出可執行的下一步**（點名、限時、裁決） |
| 4 | 選擇正確但**話太長**（≥4 句）或**沒給下一步** |
| 3 | **該軟插入卻硬打斷**（或反之），但沒造成明顯不適 |
| 2 | 打斷方式造成**場面停滯**（介入後 ≥5 秒無人接話） |
| 1 | **蓋在別人講話上未讓步**，或 **30 秒內第二次介入**（碎念） |

> 「30 秒內第二次」直接對應動態門檻的 `+1.0` 冷卻規則——**這維度同時是那條規則的驗收**。

### 維度 5：效果 —— 介入後 60 秒觀察

| 分 | 判準 |
|---|---|
| 5 | **目標行為出現**：被點名者開口／講者收尾／話題回到議題／裁決被接受並記錄 |
| 4 | **部分出現**（講者收尾但話題沒回到議題） |
| 3 | **有回應但沒改變行為**（有人「喔好」然後照舊） |
| 2 | **被忽略**，會議照原樣繼續 |
| 1 | **產生負面效果**：與會者抱怨／氣氛停滯／有人此後不再發言 |

> ⚠️ **這維度在 dogfooding 內部場會被系統性高估**——自己人會不自覺配合 AI。
> **內部場與外人場的 Effect 分必須分開統計，不要合併平均。**

## 第 2 層：整場會議評分（改編自 Inner Thoughts Table 3）

| 維度 | 陳述句（1–7，1 ＝ 非常不同意） | 來源 |
|---|---|---|
| Turn Appropriateness | AI 主席開口的時機在情境與邏輯上都恰當 | 原文改寫 |
| Coherence | 這場會議的議題推進保持連貫 | 原文改寫 |
| Adaptability | AI 主席能因應會議動態的變化調整做法 | 原文改寫 |
| **Fairness** | AI 主席讓每個人都有合理的發言機會 | 我們補 |
| **Decisiveness** | 討論卡住時，AI 主席能做出明確裁決並說明理由 | 我們補 |
| **Non-obtrusiveness** | AI 主席的介入沒有妨礙我們原本的討論 | 我們補 |

**刪掉的兩題**：Anthropomorphism（我們明確不做人格）、Perceived Intelligence（與主持品質無關）。

> ⚠️ **必須配合強制配對比較**：同場景跑兩組參數，讓評分者**二選一並用具體例子說明理由**。
> 這是 Inner Thoughts 全篇唯一真正跑出分辨力的方法
> （配對偏好 82% 顯著；§7 的三條件 Likert 幾乎全不顯著）。

## 第 3 層：自動化指標（無需人工，即時可算）

> 這一層是從兩篇論文的**失敗模式描述**推導的代理指標，**不是論文原文**。

| 指標 | 抓什麼問題 | 對照基準 |
|---|---|---|
| 介入次數／小時 | 過度熱衷 vs 過度被動 | D&D 案例：user-initiated ≈ always-active 的 **1/5** |
| 介入間隔中位數 | 碎念 | 應 > 30 秒冷卻期 |
| **首次介入延遲** | PTFA 失敗模式 A（8 分鐘才第一次介入） | 應在發散期結束前 |
| **「每人講完就介入」比例** | PTFA 失敗模式 B | 應遠低於 1.0 |
| 硬打斷／軟插入比例 | 方式選擇偏差 | 硬打斷應為少數 |
| 沉默者被點名後 60 秒內開口率 | 「點名」介入的有效性 | 直接對應維度 5 |
| 發言時間 Gini、最高佔比 | 發言權分配失衡 | 介入前後對比才有意義 |
| 介入後 60 秒內說話者切換數 | 有沒有讓場子動起來 | 與介入前 60 秒對比 |

**用途**：不能單獨判定好壞，但可當第 1 層人工標註的**觸發器**——任一項超出區間就去看那段逐字稿。
而且**全部從 log 就能算**，做完立刻有調參訊號，還能直接當 demo 觀戰畫面的內容。

## 8 天時程下的最小可行做法

跳過第 2 層（需要多場 A/B 與足夠評分者，時間不夠）。做三件事：

1. **第 3 層自動化指標先接上** —— log 就能算，立刻有訊號，且是 demo 素材
2. **每場 dogfooding 事後標 10–20 個介入事件**，用第 0 層四象限 ＋ 第 1 層五維，兩人標
3. **外人場的 Effect 分單獨計**，不與內部場合併

第 1 層五維表可以直接印出來當標註表用。

## 已知缺口

1. **「該介入」的 ground truth 定義：兩篇都沒有。** 第 0 層標註手冊必須自己寫。
   **這是整套評分表最脆弱的一環。**
2. **每一級量表的文字定義：Inner Thoughts 沒有**（只有兩端錨點 1／7，中間五級無定義）。
   它的題目改編自 Borsci et al. 2022、Wang et al. 2021、**Bartneck et al. 2009（Godspeed 量表）**——
   要有文獻背書的逐級錨點，那三篇是下一個要讀的來源。
3. **中文即時語音會議的標註資料：不存在。**
4. **沒有 benchmark 可對照絕對分數**，只能做同場景 A/B 相對比較。

## 附錄：已取代的第 0 層（介入事件四象限、F1p/F1n）

> 本節已由窗口計分取代（見文首），保留供參，不再是驗收依據。

### 標註流程

1. 兩名**未參與該場會議**的標註者，各自看逐字稿 ＋ 發言時間軸，
   **在 AI 發言被遮蔽的情況下（盲標）**，逐一評分
2. **盲標用三欄各自 1–5 分，不是二元標記**（依據 `prior-art.md` 發現 1c）：

   ```
   該鼓勵某人發言      : 1-5
   該抑制某個行為      : 1-5
   此刻不需要任何介入  : 1-5   ← 獨立填，不是前兩者的殘差
   ```

   **好處**：ground truth 本身帶強度資訊，第 1 層維度 1（必要性）可以拿它當校準基準，
   而不是讓標註者憑印象重打一次。

3. 三軸分數 → 「該不該介入」用**與產品同一條規則** `slow_path.is_intervention()`（`decide()` 相對比較、「不介入」軸有否決權，再加 `type=無` 視為不介入），
   不用論文 Table 10 的「任一軸 ≥3」——那條在我們的場景實測誤報 60–80%（validation-results.md #3b），
   且人標與產品若用兩套規則，同一份標註會得到兩種答案，F1 就失去意義。兩人比對，**只保留兩人都標的時點**為 ground truth；
   不一致的另存，作為「判準模糊」的證據
4. 與 AI 實際介入時間軸對齊，容忍窗口 **±1 個發言輪次**

| | AI 有介入 | AI 沒介入 |
|---|---|---|
| **標註者認為該介入** | TP | **FN 漏接** |
| **標註者認為不該介入** | **FP 誤報** | TN |

### 產出：分開報 F1p 與 F1n，套用崩潰守門

```
F1p  該介入時抓到了嗎
F1n  不該介入時忍住了嗎
守門：任一 < 0.15 → 模型行為崩潰，該組參數直接作廢
```

**為什麼不是單一指標**：論文 Table 4 顯示模型會**兩極崩壞**——
OLMo7B 的 Recall 0.986 / F1n 0.007（幾乎每則都插話），Qwen32B 的 Recall 0.105（幾乎不插話）。

- 單看 **Precision** 只擋得住其中一種崩壞
- 單一 **macro-F1** 兩種都掩蓋

> FP 成本仍然 > FN 成本（Overhearing Challenge 2：使用者不願承擔驗證誤報的認知負荷，
> 而會議情境比寫作情境更強烈——與會者正在思考與說話）。
> 但**這體現在權衡取捨上，不是靠只看一個指標**。

另外產出**分類型混淆矩陣**（該介入「離題」卻介入成「超時」＝部分正確，單獨計）。
