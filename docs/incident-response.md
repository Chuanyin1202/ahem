# 資安事件應變流程

## 觸發條件

Token／金鑰疑似外洩、未授權存取、逐字稿外流、加密驗證失敗、異常大量下載或第三方
服務回報事故，均視為資安事件。

## 0–15 分鐘：控制

1. 停止 Ahem 與對外入口。
2. 撤銷 Viewer、Operator、Discord、ElevenLabs、OpenAI 憑證。
3. 隔離受影響裝置，不刪除稽核證據。

## 15–60 分鐘：判定

1. 確認會議編號、資料類型、時間範圍及可能接觸者。
2. 保存不含明文的日誌、檔案雜湊與時間線。
3. 通知專案負責人及隱私聯絡窗口。

## 後續

依適用法規與契約判斷通知義務；完成根因、修補、金鑰輪替及回歸測試後才能恢復。
復原後撰寫不含個資的事後報告，將預防措施加入 CI 或 Runbook。
